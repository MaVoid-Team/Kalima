Build Sequence

Subagent Rules

  • Subagents should not edit overlapping files at the same time.
  • Each subagent returns changed files, tests run, risks, and unresolved questions.
  • The main agent reviews all patches before applying or committing them.
  • The main agent owns migrations, final contracts, and final verification.

First Coding Slice

  1. Run Phase 0 baseline.
  2. Add schema and migrations.
  3. Add service skeletons.
  4. Add focused tests for template deletion and batch snapshots.
  5. Do not build UI until contracts are stable.

Non-Negotiable Risks

Generated codes do not reserve seats, so redemption can fail later if seats are exhausted. The admin UI and batch status must warn about this.
Risk Mitigation Proof Required
Arabic rendering fails in production PDF runtime. Bundle or configure an Arabic-capable font. Generated PDF visual proof.
QR URL tampering changes entitlement context. Use signed opaque references. Tamper rejection tests.
Private print assets leak through public URLs. Use private e-booklet file assets and admin-only download endpoints. Permission tests.
Old batch history disagrees with edited templates. Snapshot template layout and batch values at generation time. Snapshot immutability tests.
