E-Booklet Access Code Print Batches

A spec for copying Fekra's promo-code print workflow into Kalima as an e-booklet access-code batch system for teacher-owned booklet instances.

827 x 438 px Fixed card source size at 300 PPI.
1 card = 1 student Single successful redemption per printed code.
Admin only Teachers do not download generated PDFs in v1.

Core Flow

Select teacher booklet instance
Fill batch fields and presets
Preview backend-rendered card
Generate codes and PDF
Student logs in and confirms redemption

Important Constraint

Generated codes do not reserve seats. Redemption re-checks remaining seats, and seat exhaustion fails gracefully without burning the code.

Printable Fields

Field Rule
QRRequired and unique per code.
Code numberRequired and same access-code string as QR flow.
Teacher imageOptional and uploaded only in generator.
PricePlain optional text and not shown during redemption.
Registration methodControlled preset with override.
Grade or classControlled preset with free-text override.
Red custom textFree text per batch.

Architecture

  • Use existing Kalima e-booklet access codes as entitlement source of truth.
  • Use server-side rendering for preview and final PDF.
  • Store template image, teacher image, and PDF as private e-booklet file assets.
  • Use signed opaque QR references instead of raw Arabic query params.
  • Snapshot template layout and batch values at generation time.
