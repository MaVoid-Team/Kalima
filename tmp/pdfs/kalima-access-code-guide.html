الفكرة العامة

نظام أكواد الوصول المطبوعة يسمح للإدارة بإنشاء بطاقات ورقية أو PDF لكل طالب.

كل بطاقة تحتوي على رمز QR ورقم كود ومعلومات اختيارية مثل صورة المدرس، الصف، طريقة التسجيل، السعر، وتنبيه نصي أحمر.

عند مسح QR يفتح الطالب صفحة تفعيل مملوءة بالبيانات، وعند إدخال الكود يفتح نفس مسار التفعيل لكن يكتب الطالب الكود بنفسه.

الأدوار

  • الإدارة: تنشئ القالب، تضبط الحقول، تولد الأكواد، وتنزل PDF.
  • المدرس أو فريق التشغيل: يطبع أو يشارك البطاقات مع الطلاب.
  • الطالب: يسجل الدخول، يقبل الشروط، ثم يفعل الكود.

المفاهيم

  • Template: شكل البطاقة الثابت.
  • Preset: نص جاهز للصف أو طريقة التسجيل.
  • Batch: دفعة PDF تحتوي على عدة بطاقات.
  • Paid code: يحتسب في المقاعد المدفوعة والمكافآت.
  • Free code: يمنح وصولا بدون احتساب كمدفوع.

إنشاء قالب بطاقة الكود

  1. 1افتح لوحة الإدارة ثم E-Booklets ثم تبويب Teacher Access.
  2. 2في قسم Print templates اكتب اسم القالب.
  3. 3ارفع صورة خلفية البطاقة أو أدخل Background asset ID لو كانت الصورة مرفوعة مسبقا.
  4. 4استخدم خلفية بمقاس 827 x 438 px عند 300 PPI حتى يطابق PDF التصميم.
  5. 5اضغط Create لحفظ القالب، ثم راجع ظهوره في قائمة القوالب النشطة.

تفعيل وأرشفة القالب

القالب النشط يظهر عند إنشاء دفعة PDF جديدة. استخدم Archive لإخفاء قالب قديم بدون حذف تاريخه.

حذف القالب

القوالب المستخدمة في دفعات موجودة قد لا تقبل الحذف، لأن الدفعات تحتاج إلى مرجع ثابت للتدقيق وإعادة التنزيل.

Presets

أضف نصوصا جاهزة لنوعين: طريقة التسجيل أو نص الصف. هذا يقلل أخطاء الكتابة عند تكرار الدفعات.

Preview

بعد اختيار القالب داخل الدفعة استخدم Preview card للتأكد من أن QR والكود والصورة والنصوص في أماكنها.

إنشاء الأكواد قبل الطباعة

  1. 1من قائمة المدرسين افتح نسخة المذكرة الخاصة بالمدرس.
  2. 2اضغط Access codes.
  3. 3اختر Term الصحيح حتى ترتبط الأكواد بالشروط والمكافآت الصحيحة.
  4. 4اختر نوع الكود: Paid code أو Free code.
  5. 5حدد عدد الأكواد، وعدد مرات الاستخدام لكل كود، وتاريخ الانتهاء إذا كان مطلوبا.
  6. 6اضغط Generate codes إذا كنت تريد أكواد عادية غير مطبوعة.
للبيع الفردي اطبع كودا واحدا لكل طالب واجعل Max redemptions يساوي 1. الكود المدفوع المعاد استخدامه لا يفتح إلا لنفس حساب الطالب الذي فعله أول مرة.

إنشاء دفعة PDF مطبوعة

  1. 1افتح قسم Printable PDF batch.
  2. 2اختر القالب من Template ID.
  3. 3اكتب اسم الدفعة حتى يسهل الرجوع إليها لاحقا.
  4. 4ارفع صورة المدرس أو أدخل Asset ID للصورة.
  5. 5املأ الصف، طريقة التسجيل، السعر، والنص الأحمر. يمكنك استخدام Preset أو كتابة النص مباشرة.
  6. 6حدد الحقول المطلوبة إذا كان يجب منع التوليد قبل إدخالها.
  7. 7اضغط Preview card قبل التوليد.
  8. 8اضغط Generate printable PDF. كل بطاقة مطبوعة تساوي كود طالب واحد.
Printable Batch5

تنزيل ومشاركة ملف PDF

بعد التوليد تظهر الدفعة في Generated PDF batches وبجانبها زر PDF.

اضغط PDF لتنزيل الملف، ثم اطبعه أو أرسله للمدرس أو فريق التوزيع. لا تنشر الملف في قناة عامة لأن كل بطاقة تحمل كودا صالحا لطالب.

إذا كانت البطاقة للشراء الفردي، سلم بطاقة واحدة لكل طالب. إذا كان الكود مجانيا أو مشتركا، تأكد أن عدد مرات الاستخدام يناسب السياسة المطلوبة.

قواعد المشاركة الآمنة

  • لا تشارك لقطة شاشة للكود في مجموعات عامة.
  • استخدم دفعة جديدة إذا تم تسريب ملف PDF قبل التوزيع.
  • احتفظ باسم دفعة واضح يتضمن المدرس أو المجموعة أو التاريخ.
  • راجع عدد البطاقات قبل الطباعة حتى لا تطبع أقل أو أكثر من المطلوب.

استخدام الطالب عبر QR

قبل تسجيل الدخول

عند مسح QR بدون جلسة طالب، تعرض كلمة رسالة تطلب تسجيل الدخول أو التسجيل كطالب أولا.

بعد تسجيل الدخول

تعرض صفحة التفعيل بيانات المدرس والمذكرة والصف وطريقة التسجيل وصورة المدرس والكود المملوء تلقائيا.

Student QR Use8

متابعة الاستخدام بعد التفعيل

  • من تبويب Teacher Access افتح نسخة المدرس لمراجعة المقاعد المستخدمة.
  • قسم Students with access يعرض الطلاب الذين فعلوا الوصول.
  • تظهر حالة الكود كمدفوع أو مجاني، نشط أو مستخدم، ومعها عدد مرات التفعيل.
  • استخدم Manage devices لمعالجة قيود الأجهزة عند الحاجة.
  • استخدم Revoke فقط عند الحاجة لإلغاء وصول المدرس أو النسخة حسب سياسة التشغيل.

قائمة فحص قبل التسليم

القالب

  • المقاس 827 x 438 px.
  • QR واضح.
  • رقم الكود واضح.
  • القالب Active.

الدفعة

  • Term صحيح.
  • Paid أو Free صحيح.
  • عدد البطاقات صحيح.
  • PDF تم تنزيله.

الطالب

  • لديه حساب طالب.
  • قبل الشروط.
  • الكود غير منتهي.
  • الوصول ظهر في حسابه.

ملخص سريع

أنشئ قالبا ثابتا، اضبط الحقول المتغيرة، افتح نسخة المدرس، اختر إعدادات الكود، أنشئ دفعة PDF، شارك بطاقة واحدة لكل طالب، ثم يتبع الطالب QR أو صفحة الإدخال اليدوي لتفعيل الوصول.

كلما كان اسم الدفعة واضحا والقالب مضبوطا من البداية، أصبح تتبع الأكواد والطباعة وإعادة التنزيل أسهل وأكثر أمانا.
